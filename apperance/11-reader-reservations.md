## 2. 页面标题

| 属性 | 值 |

| 属性 | 值 |

| 背景 | `$bg-primary` |
| 圆角 | 10px |
| 边框 | 1px solid `$border` |

## 4. 预约卡片

每项预约使用一个卡片展示。

| 属性 | 值 |
|------|-----|
| 背景 | `$bg-primary` |
| 圆角 | `$card-radius` (16px) |
| 边框 | 1px solid `$border` |
| 内边距 | 20px |
| 间距 | 16px |
| 对齐 | 水平居中 |

### 左侧信息组
| 属性 | 值 |
|------|-----|
| 布局 | 垂直 |
| 间距 | 6px |

| 字段 | 样式 |
|------|------|
| 书名 | Inter 16px Semibold 600, `$text-primary` |
| 作者 | Inter 13px, `$text-secondary` |
| 预约时间 | Inter 12px, `$text-muted`, 格式"预约时间：2026-07-20" |

### 右侧操作组
| 属性 | 值 |
|------|-----|
| 间距 | 12px |
| 对齐 | 垂直居中 |

| 元素 | 样式 |
|------|------|
| 状态标签 | `$accent-light` 背景, 圆角 999px, 内边距 6px 14px, Inter 12px Medium 500, `$accent` |
| 取消预约 | Inter 13px Medium 500, `$danger`, 可点击 |

### 状态颜色

| 状态 | 标签背景 | 文字颜色 |
|------|---------|---------|
| 等待中 | `$accent-light` | `$accent` |
| 待取书 | `$success` 半透明 | `$success` |
| 已完成 | `$text-muted` 半透明 | `$text-muted` |
| 已取消 | `$danger` 半透明 | `$danger` |
| 已过期 | `$text-muted` 半透明 | `$text-muted` |
