## 3. Tab 切换栏

| 属性 | 值 |
|------|-----|
| 间距 | 4px |
| 背景 | `$bg-primary` |
| 圆角 | 10px |
| 边框 | 1px solid `$border` |
| 内边距 | 3px |

| Tab | 默认状态 |
|-----|---------|
| **未缴罚款** | ✅ 选中 |
| 已缴记录 | 未选中 |

按钮规格: 同 [10-reader-history.md](10-reader-history.md) 的快捷日期按钮

## 4. 罚款卡片

每项罚款使用一个卡片展示。

| 属性 | 值 |
|------|-----|
| 背景 | `$bg-primary` |
| 圆角 | `$card-radius` (16px) |
| 边框 | 1px solid `$border` |
| 内边距 | 20px |
| 间距 | 16px |
| 对齐 | 水平居中 |

### 左侧信息组
| 属性 | 值 |
|------|-----|
| 布局 | 垂直 |
| 间距 | 6px |

| 字段 | 样式 |
|------|------|
| 书名 | Inter 16px Semibold 600, `$text-primary` |
| 类型 + 逾期天数 | Inter 13px, `$text-secondary`, 格式"逾期罚款 · 逾期 9 天" |
| 生成时间 | Inter 12px, `$text-muted`, 格式"生成时间：2026-07-17" |

### 中间金额
| 属性 | 值 |
|------|-----|
| 字体 | Inter 22px Bold 700 |
| 颜色 | `$danger` |
| 格式 | ¥4.50 |

### 右侧按钮
| 属性 | 值 |
|------|-----|
| 背景 | `$accent` |
| 圆角 | `$button-radius` (10px) |
| 内边距 | 10px 20px |
| 文字 | Inter 13px Semibold 600, `$text-inverse`, "立即缴纳" |
