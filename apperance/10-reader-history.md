## 2. 页面标题

| 属性 | 值 |
|------|-----|
| 标题 | "借阅历史" — Inter 24px Bold 700, `$text-primary` |

## 3. 时间筛选行

| 属性 | 值 |
|------|-----|
| 间距 | 12px |
| 对齐 | 垂直居中 |

### 快捷日期按钮
| 属性 | 值 |
|------|-----|
| 容器 | 间距 4px, `$bg-primary` 背景, 圆角 10px, 1px solid `$border`, 内边距 3px |

每个按钮:
| 属性 | 值 |
|------|-----|
| 圆角 | 8px |
| 内边距 | 8px 14px |
| **选中** | `$accent` 背景, `$text-inverse` 文字, 字重 600 |
| **未选中** | `$bg-primary` 背景, `$text-secondary` 文字, 字重 500 |
| 字体 | Inter 12px |

| 按钮 | 说明 |
|------|------|
| 近7天 | 默认未选中 |
| **近30天** | **默认选中** |
| 近90天 | 默认未选中 |
| 全部 | 默认未选中 |

### 日期范围选择器
| 元素 | 样式 |
|------|------|
| 起始日期框 | 宽 140px, `$bg-primary` 背景, `$input-radius` 圆角, 1.5px solid `$border`, 内边距 10px 14px, Inter 13px `$text-secondary` |
| 分隔符 "—" | Inter 14px, `$text-muted` |
| 结束日期框 | 同起始日期框 |

## 4. 统计卡片行

同 [09-reader-borrowing.md](09-reader-borrowing.md) 的统计卡片样式。

| 统计项 | 数值颜色 |
|--------|---------|
| 总借阅 | `$accent` |
| 总归还 | `$success` |
| 总逾期 | `$danger` |

## 5. 历史记录表格

### 表头
| 属性 | 值 |
|------|-----|

| 内边距 | 14px 20px |

| 列 | 宽度 |

| 借出日期 | 120px |

|------|------|

| 逾期归还 | `$warning` |

所有列的文字规格同 [09-reader-borrowing.md](09-reader-borrowing.md)。
