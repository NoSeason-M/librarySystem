## 3. 图书网格

| 属性 | 值 |
|------|-----|
| 布局 | 2 行, 每行 2 列 |
| 间距 | 16px |

### 图书卡片

| 属性 | 值 |
|------|-----|
| 背景 | `$bg-primary` |
| 圆角 | `$card-radius` (16px) |
| 边框 | 1px solid `$border` |
| 布局 | 垂直 |
| 内部间距 | 10px |

### 封面区
| 属性 | 值 |
|------|-----|
| 高度 | 140px |
| 背景 | `$accent-light` |
| 内容 | 居中显示 📖 |

### 信息区
| 属性 | 值 |
|------|-----|
| 内边距 | 14px 14px 10px 14px |
| 布局 | 垂直 |
| 间距 | 4px |

| 字段 | 样式 |
|------|------|
| 书名 | Inter 14px Semibold 600, `$text-primary` |
| 作者 | Inter 12px, `$text-secondary` |

### 操作区
| 属性 | 值 |
|------|-----|
| 内边距 | 0 14px 14px 14px |
| 对齐 | 右对齐 |

| 元素 | 样式 |
|------|------|
| 取消收藏 | Inter 12px Medium 500, `$danger`, 可点击 |
