## 2. 页面标题

| 属性 | 值 |
|------|-----|
| 标题 | "当前借阅" — Inter 24px Bold 700, `$text-primary` |
| 对齐 | 左对齐 |

### 搜索栏
| 属性 | 值 |
|------|-----|
| 背景 | `$bg-primary` (#FFFFFF) |
| 圆角 | 999px (pill) |
| 边框 | 1.5px solid `$border` |
| 内边距 | 4px 6px 4px 20px |
| 间距 | 8px |

- 🔍 图标: Inter 14px, `$text-muted`
- 占位文字: "搜索图书..." — Inter 13px, `$text-muted`
- 搜索按钮: Inter 13px Semibold 600, `$text-inverse`, `$accent` 背景, 圆角 999px, 内边距 10px 20px

## 3. 统计卡片行

| 属性 | 值 |
|------|-----|
| 布局 | 水平 |
| 间距 | 16px |

每张统计卡片:
| 属性 | 值 |
|------|-----|
| 背景 | `$bg-primary` |
| 圆角 | `$card-radius` (16px) |
| 边框 | 1px solid `$border` |
| 内边距 | 20px |
| 布局 | 垂直, 间距 6px, 文字居中 |

| 字段 | 标签 | 数值颜色 |
|------|------|---------|
| 当前在借 | Inter 12px, `$text-muted` | `$accent`, 28px Bold 700 |
| 逾期 | Inter 12px, `$text-muted` | `$danger`, 28px Bold 700 |
| 已还本月 | Inter 12px, `$text-muted` | `$success`, 28px Bold 700 |

## 4. 借阅表格

| 属性 | 值 |
|------|-----|
| 背景 | `$bg-primary` |
| 圆角 | `$card-radius` (16px) |
| 边框 | 1px solid `$border` |
| 内部间距 | 2px |

### 表头
| 属性 | 值 |
|------|-----|
| 背景 | `$bg-secondary` |
| 内边距 | 14px 20px |

| 列 | 宽度 | 样式 |
|----|------|------|
| 书名 | 200px | Inter 12px Semibold 600, `$text-muted` |
| 条码号 | 160px | 同上 |
| 借出日期 | 120px | 同上 |
| 应还日期 | 120px | 同上 |
| 状态 | 100px | 同上 |
| 操作 | 80px | 同上 |

### 数据行
| 属性 | 值 |
|------|-----|
| 内边距 | 12px 20px |
| 边框 | 0.5px solid `$border` (上方) |

| 列 | 样式 |
|----|------|
| 书名 | Inter 13px Medium 500, `$text-primary` |
| 条码号 | Inter 12px, `$text-secondary` |
| 借出日期 | Inter 12px, `$text-secondary` |
| 应还日期 | Inter 12px, 正常=`$text-secondary`, **逾期=`$danger` Semibold 600** |
| 状态标签 | Inter 11px Medium 500, 正常=`$success`, 逾期=`$danger` |
| 操作 | 可续借=`$accent` "续借", 不可续借=`$text-muted` "—" |

### 状态示例

| 状态 | 文字 | 颜色 |
|------|------|------|
| 正常 | "剩余12天" | `$success` |
| 逾期 | "逾期19天" | `$danger` |
